# Website imagery direction and Gemini prompts

## Direction: fewer boxes, more visual storytelling

Use **editorial scenes for the main pages** and **tactile 3D illustrations for donation purposes**. Keep the warm cream, lagoon, sun-yellow, and terracotta palette.

Images should replace empty covers or repetitive decoration, not sit behind every paragraph.

| Page       | Proposed placement                                                                   |
| ---------- | ------------------------------------------------------------------------------------ |
| Home       | A strong hero image; reuse education and community scenes for the two project covers |
| About      | One wide visual beside the story; retain the real-team-photo placeholder             |
| What we do | One large education/accessibility scene to interrupt the six-card grid               |
| Contact    | Replace the hero's extra text card with a welcoming community scene                  |
| Donate     | Four illustrated purpose-card covers, replacing the large icon blocks                |
| Checkout   | No additional imagery: keep attention on the selection and unavailable notice        |

## Integration guidelines

- Keep titles, prices and buttons on clean surfaces beneath the images.
- Use subtle CSS gradient overlays rather than relying solely on generated fades.
- Shorten redundant card copy where the imagery already communicates the idea.
- Label generated editorial scenes as illustrative; never imply they document TunisAid's actual projects.
- Preserve the real-team-photo placeholder until genuine photography is supplied.
- Review generated anatomy, wheelchair geometry, accessibility and cropping before use.
- Return the eight images using the filenames above for integration.
